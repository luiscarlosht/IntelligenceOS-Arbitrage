> Please specify allowed use, retention, redistribution restrictions and any

credentials in chat or commit commercial catalogs to Git.

## Acceptance and collection gate

Use [authorized import instructions](AUTHORIZED_IMPORTS.md) and the header-only
`templates/authorized_products.csv`. Capture actual source observation times;
export/download time cannot refresh older price or stock evidence. Do not infer
unit quantity from a case price. Ask the supplier to resolve absent UPC, package,
price or availability fields. Preserve the original permitted file and map fields
without inventing values. Run preflight privately; stale evidence is rejected.
Permission to store a sample does not automatically authorize refresh automation.
